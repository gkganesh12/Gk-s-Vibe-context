# 🚀 Simple Guide - Vibe Context Extension

## ✨ Three Easy Ways to Use

### 1️⃣ **Keyboard Shortcuts** (Easiest!)

Just press these keys:

- **`Cmd+Shift+V`** → Start Session
- **`Cmd+Shift+E`** → End Session  
- **`Cmd+Shift+X`** → View Summary
- **`Cmd+Shift+C`** → Copy Context for AI

That's it! No Command Palette needed.

---

### 2️⃣ **Status Bar Button** (Click It!)

Look at the **bottom right** of VS Code/Cursor:

- **`▶ Start Session`** → Click to start
- **`■ End Session`** → Click to end (when active)

The button changes automatically when you have an active session!

---

### 3️⃣ **Command Palette** (If you prefer)

Press `Cmd+Shift+P` and type:
- `Start Session`
- `End Session`
- `Explain From Memory`
- `Get Context for AI`

---

## 🎯 Quick Start (30 seconds)

1. **Press `Cmd+Shift+V`** (or click the status bar button)
2. Enter your intent (or skip)
3. Code normally - files are tracked automatically
4. **Press `Cmd+Shift+E`** when done
5. **Press `Cmd+Shift+X`** to see summary
6. **Press `Cmd+Shift+C`** to copy context for AI

---

## 📋 What Gets Tracked Automatically

✅ Files you edit  
✅ Code snippets  
✅ Timestamps  
✅ Git changes (if available)

You just need to:
- Start session (one click/keypress)
- End session (one click/keypress)
- Optionally add intent/decisions

---

## 🎨 Visual Indicators

**Status Bar (bottom right):**
- `▶ Start Session` = No active session
- `■ End Session` = Session is active (orange background)

**Notifications:**
- Green message when session starts
- Green message when session ends
- Shows file count

---

## 💡 Pro Tips

1. **Auto-start**: Just start editing - extension will ask if you want to start a session
2. **Quick context**: Press `Cmd+Shift+C` anytime to copy context to clipboard
3. **View anytime**: Press `Cmd+Shift+X` to see your last session summary

## 🐛 Troubleshooting

**Shortcuts not working?**
- Reload window: `Cmd+Shift+P` → "Developer: Reload Window"

**Status bar button missing?**
- Check Output panel for errors
- Make sure extension is enabled

**Want to change shortcuts?**
- Go to: `Code > Preferences > Keyboard Shortcuts`
- Search for "Vibe Context"
- Click the pencil icon to customize
